# POLAR COMMAND ❄️
### Antarctic Digital Twin Platform (SIH26060)

> Real-time Digital Twin platform for remote operations, risk prediction, infrastructure monitoring, and logistics optimization across Maitri and Bharati stations in Antarctica.

---

## 🚀 Key Features

- **🌐 3D Digital Twin**: Interactive 3D visualization of station structures, sensors, and ambient environments powered by Three.js.
- **⚡ Energy & Microgrid Management**: Real-time telemetry, load balancing, solar/wind/diesel generation analysis, and anomaly tracking.
- **🌡️ Environmental Monitoring**: Live weather analytics, blizzard early warning, UV/radiation indexes, and structural stress metrics.
- **📦 Logistics & Supply Chain**: Inventory depletion forecasting, cargo manifests, requisition approvals, and resupply planning.
- **🚨 Incident & Risk Simulator**: Scenario modeling (Generator Failure, Fuel Leak, Blizzard Alert) with automated remediation SOPs.
- **📡 Offline-First & Resilient**: Local state caching, mock data simulation fallbacks, and offline connectivity status banners.

---

## 🛠️ Tech Stack

- **Framework**: Next.js 14 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **3D Visualization**: Three.js & Lucide React
- **Data Visualization**: Recharts
- **Testing**: Vitest

## 📦 Getting Started

### Prerequisites

- Node.js 18+
- npm or yarn

### Installation

```bash
git clone https://github.com/Rahulcoder-881/polar-command.git
cd polar-command
npm install
```

### Running Locally

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Building for Production

```bash
npm run build
npm start
```
